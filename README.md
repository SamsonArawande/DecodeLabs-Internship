## Overview

This repository documents my work throughout the Data Analytics internship at Decode Labs — a 4-week, project-based program covering the core skills of a working data analyst: data cleaning, exploratory analysis, and (as the internship progresses) further applied projects.

Each project is organized into its own folder with a cleaned dataset or workbook, a detailed PDF report, and a dedicated README explaining the approach and findings.

## Projects

### [Project 1: Data Cleaning & Preparation](./Project%201)
Cleaned a 1,200-row order dataset — handled missing values, removed duplicates, corrected formatting — and validated OrderID as the primary key with zero duplicates and zero formatting errors.

### [Project 2: Exploratory Data Analysis](./Project%202)
Analyzed the cleaned dataset to uncover patterns, trends, and outliers. Found a right-skewed order value distribution caused by legitimate bulk orders, identified underperforming and high-value product/channel segments, and checked correlations between key variables.

## Approach

Every project follows the same standard: work is done in Excel with reproducible, named steps; findings are backed by actual numbers, not assumptions; and every claim in each report maps to something verifiable in the accompanying workbook.
