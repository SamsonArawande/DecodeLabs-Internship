## Overview

This repository documents my work throughout the Data Analytics internship at Decode Labs — a 4-week, project-based program covering the core skills of a working data analyst: data cleaning, exploratory analysis, SQL querying, and data visualization.

Each project is organized into its own folder with a dataset or workbook, a detailed PDF report, and a dedicated README explaining the approach and findings. All four projects use the same order dataset, so each builds on the last.

## Projects

### [Project 1: Data Cleaning & Preparation](./Project%201)
Cleaned a 1,200-row order dataset — handled missing values, removed duplicates, corrected formatting — and validated OrderID as the primary key with zero duplicates and zero formatting errors.

### [Project 2: Exploratory Data Analysis](./Project%202)
Analyzed the cleaned dataset for patterns, trends, and outliers. Found a right-skewed order value distribution (mean about 28% above the median), confirmed 8 legitimate bulk-order outliers that do not drive the skew, and showed that the differences between products and channels are small enough to be chance.

### [Project 3: SQL Data Analysis](./Project%203)
Used SQL to query the same dataset with SELECT, WHERE, ORDER BY, GROUP BY, HAVING, and aggregations (COUNT, SUM, AVG). Found that 41% of orders were cancelled or returned and that several product rankings change when they are excluded, and confirmed that SQL results match the earlier Excel analysis.

### [Project 4: Data Visualization](./Project%204)
Built a five-page Power BI report where every page states its conclusion and answers "So what?". Found that 41% of orders were cancelled or returned, and that the product, channel and trend patterns are small or borderline.

## Approach

Every project follows the same standard: work is done with reproducible, documented steps; findings are backed by actual numbers, not assumptions; claims are kept to what the data supports; and every claim in each report maps to something verifiable in the accompanying files.
